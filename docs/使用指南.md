## 2. 接线

### 2.1 双核链路（STM32 ↔ ESP32）

```
STM32 PA2 (USART2 TX)  ────→  ESP32 GPIO17 (UART1 RX)
STM32 PA3 (USART2 RX)  ←────  ESP32 GPIO18 (UART1 TX)
STM32 GND              ────     ESP32 GND          （必须共地！）
```

> [!IMPORTANT]
> **两根信号线方向不能接反。** 接反会导致 ESP32 收不到 STM32 的波形/测量数据，
> 表现为网页能打开但波形始终不更新。

### 2.2 STM32 调试串口

```
STM32 PA9  (USART1 TX) ────→ USB-TTL RX    (115200 8N1)
STM32 PA10 (USART1 RX) ←──── USB-TTL TX
```

### 2.3 信号输入

```
CH1 = PA1 (ADC1_IN1)     0 ~ 3.3 V 直采
CH2 = PA0 (ADC2_IN0)     0 ~ 3.3 V 直采
```

> [!WARNING]
> **输入电压不得超过 3.3 V。** 本项目没有模拟前端（AFE），也没有过压保护，
> 超压会立即永久损坏 MCU。需要测更高电压时请自行加装分压/衰减电路，
> 详见 [README 的改进方案](../README.md#改进方案)。

### 2.4 完整引脚表

| 功能 | STM32 引脚 | ESP32 引脚 |
|---|---|---|
| 双核链路 UART | PA2 TX / PA3 RX | GPIO17 RX / GPIO18 TX |
| 调试串口 | PA9 / PA10 | GPIO43 TX / GPIO44 RX（板载 CH340） |
| TFT（SPI1） | PA5 SCK / PA7 MOSI / PA4 CS / PB0 DC / PB1 RST / PB10 BLK | — |
| OLED（I2C1） | PB6 SCL / PB7 SDA | — |
| 按键 K1–K4 | PC0 / PC1 / PC2 / PC3 | — |
| 蜂鸣器 | PB8 | — |
| 编码器 | PC6 = A / PC7 = B / PC8 = SW | — |
| ADC CH1 / CH2 | PA1 / PA0 | — |
| 状态灯 | — | GPIO48（板载 RGB） |

## 3. 编译与烧录

### 3.1 STM32（Keil MDK5）

1. 用 Keil MDK5 打开 `STM32F407_ProjectTemplate/project/MDK(V5)/Project.uvprojx`
2. 确认器件为 `STM32F407VETx`
3. **F7** 编译 —— 应 0 error 0 warning
4. **F8** 烧录（需 ST-Link / J-Link 等调试器）
5. 烧录成功后 STM32 自动运行：TFT 显示波形，OLED 显示状态

### 3.2 ESP32（PlatformIO）

```bash
cd esp32
pio run                 # 编译
pio run -t upload       # 烧录
pio device monitor -b 115200
```

在 VS Code 中则直接打开 `esp32` 文件夹，选择板载 CH340 对应的那个 USB-C 口，
点 **Upload** 即可。

> **首次烧录失败？** 若报 `Failed to connect`：
> **按住 BOOT → 点一下 RST → 松开 BOOT → 立刻 Upload**。
> 之后走 OTA 或正常 USB 烧录都不再需要这个动作。

### 3.3 ESP32 OTA（无线升级）

首次必须用 USB 烧录一次，之后就可以无线升级：

1. 确认 ESP32 已连上路由器且网页可访问
2. VS Code 命令面板 → `PlatformIO: Upload` → 选择网络端口
3. 或 Arduino IDE → 工具 → 端口 → 网络端口 → 选 `oscilloscope.local` 或设备 IP

### 3.4 清理构建产物

`STM32F407_ProjectTemplate/clean.bat` 会删除 Keil 生成的 `Listings/`、`Objects/`
和 `project.uvgui.*` 界面状态文件，便于打包源码。

## 4. 本机操作（TFT / OLED / 按键 / 编码器）

### 4.1 TFT 界面布局（320×240 横屏）

```
┌──────────────────────────────────────────────┐
│ 时基 3.00ms       运行/停止        10.0kHz     │ ← 状态栏 20px
│ ●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●● │   底边绿=运行 / 橙=停止
├──────────────────────────────┬───────────────┤
│                              │ 触发条 20px    │
│                              │  ◀ 三角标记    │
│        波形区 300×150         │  (红=已触发    │
│        10×6 网格              │   灰=等待)     │ 150px
│   ─ ─ ─ ─ 触发电平虚线 ─ ─ ─ ─  │               │
│         CH1(绿) CH2(黄)       │               │
├──────────────────────────────┴───────────────┤
│ ▍通道1 波峰 2000mV 平均 1000mV                │ ← 卡片1 34px
│    频率 1.00kHz 占空比 50.0%                  │
│ ▍通道2 波峰 1234mV 平均 620mV                 │ ← 卡片2 34px
│    频率 2.00kHz 占空比 25.0%                  │
└──────────────────────────────────────────────┘
```

界面要点：

- **触发电平虚线**横贯整条波形区，电平改到哪线就画到哪，波形画在虚线之上。
- **触发条三角标记**：三角形尖端指向波形区，红色 = 已触发（hit），
  灰色 = 已武装但未命中；触发源设为「关」时该区整体变暗。
- **测量卡片**：每个通道一张，左边缘 3 px 色条即通道色；通道隐藏时卡片转灰底灰字。
- **状态栏底边**兼作运行指示灯：运行时绿色、停止时橙色。
- 界面采用分层脏标记刷新：状态栏字段、两张测量卡片、触发条、菜单行各自与屏幕内容比对，
  只重画真正变化的像素，因此波形刷新不会因文字更新而抖动。

### 4.2 OLED 副屏（128×64）

| 行 | 内容 |
|---|---|
| 1 | `DualCore Scope` |
| 2 | `RUN` / `STOP` |
| 3 | 时基，如 `T 300.00us` |
| 4 | 触发状态：`TR OFF` / `TR AUTO` / `TR NORM` / `TR SINGL` |

### 4.3 按键

| 按键 | 功能 |
|---|---|
| K1 | 时基 ↓（降速） |
| K2 | 时基 ↑（升速） |
| K3 | Run / Stop 切换 |
| K4 | 打开 / 关闭菜单 |

### 4.4 编码器

| 操作 | 功能 |
|---|---|
| 旋转（菜单关闭） | 时基 ↑ / ↓ |
| 旋转（菜单打开，非编辑） | 菜单项滚动 |
| 旋转（编辑模式） | 修改当前项的值 |
| 按下（菜单关闭） | 打开菜单 |
| 按下（菜单打开，非编辑） | 进入编辑 / 切换选项 |
| 按下（编辑模式） | 退出编辑 |

### 4.5 菜单（10 项）

| # | 菜单项 | 操作 |
|---|---|---|
| 1 | 时基 | 进入编辑后旋转调采样率（13 档：100 Hz ~ 1 MHz） |
| 2 | V/div | 进入编辑后旋转调垂直缩放（4 档） |
| 3 | CH1 | 按下切换显示 / 隐藏 |
| 4 | CH2 | 按下切换显示 / 隐藏 |
| 5 | 触发源 | 按下循环：关 → CH1 → CH2 → 关 |
| 6 | 边沿 | 按下切换：上升沿 / 下降沿 |
| 7 | 电平 | 进入编辑后旋转调触发电平（0 ~ 4095 → 0 ~ 3300 mV） |
| 8 | 模式 | 按下循环：自动 → 常态 → 单次 |
| 9 | 测量 | 按下切换显示 / 隐藏测量值 |
| 10 | 退出 | 关闭菜单 |

## 5. 网页示波器

### 5.1 首次上电：用设备自带热点配网

固件里**不包含任何 Wi-Fi 凭据**，所以第一次上电会直接自建配置热点，
不会白等连接超时：

```
[WIFI] no credentials stored
[WIFI] no router — starting setup AP
```

1. 手机或电脑连接热点 **`Oscilloscope-Setup`**，密码 **`12345678`**
2. 浏览器打开 **http://192.168.4.1/**
3. 展开页面底部的「WiFi 设置」，填入你的路由器 SSID 和密码 →「保存 WiFi」→「重启生效」

页面顶部会出现橙色横幅提示「设备未连接路由器，已自动开启热点」，
并自动展开 WiFi 设置面板。

### 5.2 之后每次上电：查看 IP

ESP32 从 NVS 读出上次保存的凭据去连路由器。打开串口监视器（115200）可看到启动日志：

```
[WIFI] connecting to "你的WiFi名" (saved from web page) ...
[WIFI] connected to "你的WiFi名" (saved from web page)
[WIFI] IP 192.168.1.42 (RSSI -55 dBm)
[WIFI] open http://192.168.1.42/ on your phone/laptop
[WEB] serving on 192.168.1.42 (SSID "你的WiFi名")
[OTA] ready (use Arduino IDE/PlatformIO 'Upload OTA')
```

若 15 秒内连不上路由器（改了密码 / 换了路由器），会自动回落到设置热点，
重新配一次即可，**不需要重新烧录**。

### 5.3 打开网页

手机或电脑连接**同一个 Wi-Fi**，浏览器打开日志里显示的 IP，
或直接访问 **http://oscilloscope.local**（mDNS）。

### 5.4 网页功能

- **顶栏**：`运行/停止` 状态徽章（绿 / 橙）+ 一行状态摘要（时基 · 触发模式 · 边沿 · 触发通道）
- **波形区**：300×150 逻辑画布，自适应浏览器宽度等比放大；
  CH1 绿 / CH2 黄，10×6 网格，10 Hz 刷新
- **触发电平虚线**：直接画在网页波形上，右侧带 `xxxx mV` 气泡
- **拖动设电平**：用鼠标或手指在波形区拖动即可设置触发电平
  （拖动时节流 120 ms，松手立即下发一条命令）
- **控制条**
  - `▶ 运行` / `■ 停止`
  - 时基下拉（13 档：100 Hz ~ 1 MHz）
  - 触发配置：模式（自动 / 常态 / 单次）、边沿（上升沿 / 下降沿）、通道（CH1 / CH2）
  - 电平滑块 + 数值
- **测量卡片**：CH1 / CH2 各一张，显示波峰 / 平均 / 频率 / 占空比，2 Hz 更新
- **CSV 导出**：点「下载 CSV」下载 300 行原始采样数据，可直接用 Excel 或 Python 分析
- **OTA**：可用 PlatformIO 或 Arduino IDE 通过网络端口上传新固件
- 页面切到后台（`document.hidden`）时自动停止轮询，回到前台自动恢复
- STM32 尚未上报数据时页面显示「等待 STM32 数据…」；网络中断时显示「连接中断，正在重试…」

> 网页只负责显示与转发，**所有波形数据都由 STM32 产生**。
> 网页上的按钮通过 UART 转发命令给 STM32，STM32 执行后返回波形与测量数据。

### 5.5 更换 Wi-Fi（不用重新烧录）

展开页面底部的「WiFi 设置（名称 / 密码）」：

| 项 | 说明 |
|---|---|
| **名称** | 新 Wi-Fi 的 SSID（1 ~ 32 字节） |
| **密码** | 留空表示**不修改**当前密码；填了就必须 8 ~ 63 位 |
| **保存 WiFi** | 写入 ESP32 的 NVS flash，提示「已保存，重启后生效」，**本次开机不切换** |
| **重启生效** | ESP32 重启并用新凭据连接；连不上会先试固件内置默认值，再失败就进入设置热点 |
| **恢复默认** | 清除已保存的凭据，回到固件内置的两个默认数组（默认为空，于是重新进入配网热点） |

内置默认数组位于 `esp32/lib/osc_wifi/osc_wifi.cpp` 顶部：
`WIFI_SSID_DEFAULT[]` / `WIFI_PASS_DEFAULT[]`。
**默认留空**，因此设备开箱即进入配网热点。
你可以自行填入 SSID 和密码让固件开箱即连，但请注意这会把凭据**以明文编译进固件**。

> 密码**不会**回显到网页，页面只显示「密码 已设置 / 无」。

## 6. 调试

### 6.1 串口日志

**STM32 调试串口（USART1，115200）：上电打印一行，运行期静默。**

```
DualCore Scope ready
```

`bsp/uart/uart.c` 里的 `fputc` 重定向保留着，需要排查时临时加一行 `printf` 即可。
固件内可直接读取的状态量：

| 接口 | 含义 |
|---|---|
| `adc_dma_remaining()` | DMA 剩余传输数（512 = 未启动；递减 = 运行中，循环） |
| `proto_drops()` | 发送环满而丢弃的帧数 |
| `uart2_tx_free()` | 发送环剩余空间 |

**ESP32 串口（115200）：启动时打印一次，运行期静默。**

日志字段含义：

| 字段 | 含义 |
|---|---|
| `IP` | 网页地址（DHCP 分配，每次上电可能不同） |
| `RSSI` | 信号强度，越接近 0 越好（−80 以下偏弱） |
| `(built-in default)` / `(saved from web page)` | 当前凭据来自固件数组还是网页保存的 NVS |

连不上路由器时会打印 `[WIFI] no router — starting setup AP` 并给出热点名与地址；
OTA 升级时会打印进度百分比。

### 6.2 UART 自环测试（进阶）

当网页打不开波形、怀疑 STM32 一侧收发有问题时，可以用自环测试把
「STM32 的 UART」和「PA2 → GPIO17 这段线」分开定位。

1. 断开 PA2 与 ESP32 GPIO17 的连接
2. 用杜邦线短接 STM32 的 **PA2 → PA3**（自发自收）
3. 在 `app/main.c` 里临时加一个计数器：`proto_recv()` 返回 1 时自增，
   并用 1 s 计时器打印 `printf("rx=%lu\r\n", (unsigned long)s_dbg_rx);`
4. STM32 会周期性主动发送 `RESP_STAT`（11 B 帧），自环回来后由 `proto_recv()` 收到
5. **计数每秒 +1** → STM32 收发正常，问题在 PA2 → GPIO17 连线
6. **计数不增长** → STM32 发送通路有问题
7. 测完删掉临时打印

## 7. 故障排查

| 现象 | 可能原因 | 排查 |
|---|---|---|
| TFT 不亮 | 背光线未接 / 电源不足 | 检查 PB10（BLK）接线 |
| 波形不动 | ADC 未启动 / 触发未命中 | 先看网页是否有波形；网页也静止则查 PA2 → GPIO17 |
| OLED 隔行不亮 | 模块本身问题 | 换一块 OLED 模块 |
| 网页打不开 | Wi-Fi 未连 / IP 不对 / 不在同一网络 | 看 ESP32 串口日志里的 IP |
| 网页波形不更新 | PA2 → GPIO17 断线 / STM32 未运行 | 做 6.2 的自环测试 |
| 网页控制无效 | ESP32 → STM32 方向断线或接反 | 查 PA3 ← GPIO18 连线 |
| 卡在 `[WIFI] connecting to "..."` | SSID / 密码错，或不是 2.4 GHz 网络 | ESP32-S3 只支持 2.4 GHz；等 15 s 会自动进入设置热点 `Oscilloscope-Setup`（密码 `12345678`），连上后打开 http://192.168.4.1/ 重配 |
| 新 Wi-Fi 保存了但没连上 | 保存只写 NVS，**下次开机**才生效 | 点页面上的「重启生效」；确认密码 ≥ 8 位 |
| 网页底部的 WiFi 面板打不开 | `<details>` 未展开 | 点「WiFi 设置（名称 / 密码）」一行展开 |
| 忘了 Wi-Fi 密码 / 换了路由器 | — | **不用重新烧录**：等 15 s 进入设置热点 `Oscilloscope-Setup`（密码 `12345678`），连上后打开 http://192.168.4.1/ 重配 |
| 触发不工作 | 电平不匹配信号范围 | 把电平调到信号 Vmin ~ Vmax 之间 |
| 触发始终不稳定 | 搜索窗内找不到符合方向的边沿 | 换个边沿方向或触发通道，或把电平移进信号幅度范围内 |
| 慢档（100 / 200 / 500 / 1k S/s）测频不准 | 采样率档位没生效 | 确认 Keil 已重新编译并烧录；13 档采样率由 `adc_tim_div()` 计算 |
| STM32 端编译报找不到头文件 | 新增了 `bsp/xxx` 目录但没加 IncludePaths | 在 Keil 工程里补上 Include Paths |

## 8. 技术规格

| 参数 | 值 |
|---|---|
| 采样率 | 100 Hz ~ 1 MHz（13 档） |
| ADC 精度 | 12 bit（0 ~ 4095） |
| 量程 | 0 ~ 3300 mV（直采，无 AFE） |
| 通道数 | 2（ADC1 + ADC2 规则同步双重模式） |
| 采样缓冲 | 环形 2048 点 |
| 波形长度 | 300 点 / 帧 |
| 触发模式 | 自动 / 常态 / 单次 |
| 触发类型 | 边沿（上升 / 下降） |
| 触发通道 | CH1 / CH2 |
| 触发搜索窗 | 按时间自适应，20 ~ 1748 点（默认 10 ms） |
| 测量项 | Vpp / Vmax / Vmin / Vavg / Vrms / 频率 / 周期 / 占空比 / 脉宽 |
| 双核链路 | UART 460800 8N1 + CRC-8 帧协议 |
| Wi-Fi | STA 模式连接路由器；凭据存 NVS（下次开机生效）；连不上自动开设置热点 |
| 网页功能 | 实时波形 / 测量 / 控制 / CSV 导出 / OTA / Wi-Fi 设置 |
| TFT 刷新 | ~25 fps（非阻塞局部刷新） |
| OLED 刷新 | ~3 Hz（仅更新变化的行） |
| 系统时钟 | 168 MHz（PLL 8 → 336 → 168） |
